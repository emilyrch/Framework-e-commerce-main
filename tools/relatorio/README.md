# Fontes do relatório atualizado

Entrada: `python tools/relatorio/atualizar_diagramas.py`.

Usa ReportLab e fontes Times New Roman/Consolas do Windows. Exporta PDF até a seção 10, HTML editável autocontido e diagramas SVG/ZIP. Não instalar estas bibliotecas no backend de execução; usar ambiente de documentos separado. O runtime de documentos do Codex foi utilizado nesta geração. `gerar_relatorio.py` é a base textual; a entrada aplica os diagramas acadêmicos e remove a seção 11 condicional. Os scripts auxiliares antigos foram preservados, mas não são o comando de geração vigente.

Saídas vigentes: `output/pdf/Relatorio_LPS_Ecommerce_Emily_Rocha_UFAL_atualizado.pdf`, `output/Relatorio_LPS_Emily_Rocha_atualizado_editavel.html` e `output/Diagramas_LPS_atualizados_editaveis.zip`.

As evidências de homologação são explicitamente limitadas. Nome do professor, brasão oficial e URL específico ainda precisam ser preenchidos com fonte confirmada. A versão editável pode ser aberta no navegador; alterações de texto devem ser salvas pelo botão de exportação. Capturas de execução não foram fabricadas.
